How to Run Qwen3.8-27B Locally on Your Mac with MLX

A 27B multimodal model, running on a laptop, exposed as an OpenAI-compatible API on localhost. The setup from scratch on a 24GB Apple Silicon Mac.

Qwen3.8-27B can now run locally on Apple Silicon through MLX.

One model loaded once, reachable three ways: Terminal, a browser UI, or an HTTP endpoint.

That means your Mac can act as its own AI machine:

  • run a 27B model locally
  • chat with it from Terminal
  • use vision and multimodal capabilities
  • expose it as a local API
  • connect your apps and agents to it
  • no per-token inference API bill
  • your prompts can stay on your machine

I got the 4-bit version running on a 24GB Apple Silicon Mac, so here is the setup from scratch.

01

Install Homebrew

If you already have brew, skip this.

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

After installation, Apple Silicon users may need:

echo 'eval "$(/opt/homebrew/bin/brew shellenv zsh)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv zsh)"

Verify:

brew --version
02

Install Python 3.12

brew install python@3.12

Check:

python3.12 --version

You want to see Python 3.12.x.

This matters. Using an older system Python can install an outdated version of mlx-vlm, which may not understand newer Qwen architectures.

03

Create a dedicated environment

I prefer keeping the local AI stack isolated from the rest of my Python setup.

python3.12 -m venv ~/qwen-mlx

Activate it:

source ~/qwen-mlx/bin/activate

Your Terminal should now show something like:

(qwen-mlx) yourname@MacBook %
04

Install MLX-VLM

python -m pip install --upgrade pip
pip install -U mlx-vlm

Check the installation:

python -c "import mlx_vlm; print(mlx_vlm.__version__)"

Now the runtime is ready.

05

Run Qwen3.8-27B

For a 24GB Mac, I am using the 4-bit version:

mlx-community/Qwen3.8-27B-4bit

Test it:

mlx_vlm.generate \
  --model mlx-community/Qwen3.8-27B-4bit \
  --prompt "Explain transformers in simple terms." \
  --max-tokens 256

The first run downloads roughly 16GB of model weights. After that, they are cached locally, so future launches do not download the model again.

06

Chat with Qwen directly in Terminal

Instead of sending one prompt at a time, you can start an interactive session:

mlx_vlm.chat \
  --model mlx-community/Qwen3.8-27B-4bit

Now your Terminal basically becomes your local AI chat. No browser required.

Option B: If you prefer a browser interface instead of Terminal, run:

mlx_vlm.chat_ui \
  --model mlx-community/Qwen3.8-27B-4bit

Then open:

http://127.0.0.1:7860

It handles images too.

Qwen3.8-27B can analyze them entirely on-device.

You will get a simple local chat UI running entirely on your Mac. When you are done, press Ctrl+C in Terminal to stop it and release the model from memory.

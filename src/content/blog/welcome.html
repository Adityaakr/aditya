This is the first post on the blog. It exists to show how the system works: this whole article is a single content-only HTML file dropped into src/content/blog/, and it showed up here automatically.

How a new post gets added

Every file in src/content/blog/ becomes a post. The filename turns into the URL — this one is welcome.html, so it lives at /blog/welcome. The list page and this reader page are generated from the files; there's no index to maintain by hand.

The metadata block

Each file starts with a small comment at the very top. That's where the title, date, and one-line excerpt come from: 

<!--
title: Welcome to the blog
date: 2026-06-29
excerpt: How this blog works.
-->
<p>...your article...</p>

Writing the article

After the comment, just write normal HTML — headings, paragraphs, links, lists, images, and code all get styled to match the rest of the site automatically:

  • No need to add fonts, colors, or layout — the page wraps your content.
  • Newest posts sort to the top by date.
  • Hand the HTML to Claude, or write it yourself — either way it just drops in.

Drop a file, commit, deploy — the post is live.
